# Contributing

This repository is currently documentation-only. No engine build or test command exists yet.

Implementation begins with a bounded, accepted Kanban task. It must define outcome, dependencies, sources, acceptance criteria and relevant checks. Select and pin the .NET SDK when the first C# task is accepted; do not create speculative projects in this foundation.

For research changes, include source URL, version/commit, observed facts, uncertainty and a reproducible verification method. For code, include meaningful tests of format/behavior boundaries. Use synthetic fixtures in Git; real-data tests must be optional and obtain their path from local configuration.

Keep PRs scoped and independently reviewed. Preserve local archive and game data outside version control. Check staged filenames and diff before publishing. The human maintainer performs merges.
