# Матрица функционального покрытия

Покрытие пересверено **2026-10-09** по merged main [`a8a553b7`](https://github.com/Simarglok/arcanum-steamwoven/tree/a8a553b7c406ace77ea019bf2b13251f00ecddb6), через PR #54. [Срез, метод и ограничения](README.md#база-и-происхождение); [merged поставки и незавершённые board delivery](../project/status.md). Исходное исследование 2026-10-02/03 сохранено. Позднейшие merges и движения карточек не входят в этот срез.

183 группы в 10 доменах; это не процент готовности. Данные, правила, интеграция и проверка оцениваются отдельно. «Частично» означает только названный диапазон; research/Proposal и root Done не считаются product runtime. Исторические candidate-specific synthetic/original/export/owner observations не являются новыми запусками аудита или original executable parity. Приёмка полного FR остаётся в доменном документе; статусы четырёх измерений здесь повторяют его текущую таблицу.

ARC-GPAD-005 (PR #67, влит 2026-10-14): [три шаблона/десять слотов и чек-лист](../input/gamepad-presets.md) расширяют только synthetic lab/framework для FR-PRODUCT-002/003, FR-UI-002/006/007 и preference-подслучая FR-LIFECYCLE-004. Реальные inventory/spell/skill/combat/party UI и WORLD preset integration не реализованы. Source/export/ordinary проверки прошли на exact head `d58e43c`, независимое ревью записано в PR #67; это не закрывает таблицу покрытия и физическую XboxBT/comfort/final-layout проверку владельца (L3): владелец отложил её до первого играбельного билда игры (2026-10-20).

Отдельный кандидат ARC-RENDER-010: [день и ночь в crash-site-area](../rendering/area-lighting.md) читает почасовую ambient-схему модуля, map default и слово схемы core-секторов, запускает часы WORLD-004 от `rules/gameinit.mes` и применяет пару indoor/outdoor к каждому terrain/body/actor draw item; с ARC-WORLD-010 это часы сессии: время идёт само (8× допущенного host-времени), стоит на паузе при открытой палитре или диалоге, «Game time +1 hour» — явное ожидание, а применённая схема пишется в снимок сессии. Это частичное покрытие FR-LIGHT-001..007 и FR-LIGHT-012; сон, пошаговый бой, источники света, список сохранений и оригинальный вид ночи не закрыты (часы и схему сохраняет F7/F8, ARC-WORLD-011).

Отдельный кандидат ARC-RENDER-012: [свет пещеры](../rendering/area-lighting.md#cave-ambient-and-stationary-sector-lights-arc-render-012) даёт каждой карте свою ambient-схему (у пещеры 5078 — map default 2) с общими часами и рисует неподвижные источники core-секторов (4 в пещере) решёткой 40×20 для terrain, цветом объекта по правилу оригинала (уровень F0) для тел и градиентом для стен. Это частичное покрытие FR-LIGHT-006/008/010; объектный и переносимый свет, анимация, сохранение и оригинальный вид не закрыты.

Отдельный кандидат ARC-RENDER-007: [режим crash-site-area](../rendering/crash-site-area-viewer.md) показывает весь внешний Crash Site из DATA-009 (9 core секторов, 36,864 terrain, 499 тел и 15 N/A) и затрагивает интеграцию/проверку FR-SCENE-001..006 и FR-WORLD-002..004 только в этом диагностическом viewer. Зона движения остаётся x4..8/y0..3; крыши/стены/свет, gameplay, пещера и визуальный паритет с оригиналом не реализованы. Строки ниже описывают merged baseline и этим кандидатом не перезаписаны.

После аудита ARC-WORLD-008 добавил [единое состояние сессии](../world/game-session-runtime.md): часы, GF, положение актёра, map-local изменения и строгую snapshot-схему 1 без экрана и хранилища сохранений. ARC-WORLD-009 добавил [переход в пещеру Crash Site и возврат](../rendering/terrain-viewer.md#crash-site-cave-and-return-arc-world-009) в area viewer; по нему обновлены строки FR-WORLD-006/007/008/009/011/012. ARC-WORLD-011 добавил [быстрое сохранение и загрузку на F7/F8](../rendering/terrain-viewer.md#quick-save-and-quick-load-arc-world-011): один слот с атомарной записью снимка сессии; по нему обновлены строки FR-LIFECYCLE-002/003. ARC-SCRIPT-006 перенёс [последствия диалога в состояние сессии](../scripting/dialog-conversation-runtime.md#consequences-in-the-game-session-arc-script-006) (GF, задания, слухи, LF/реакция/следование NPC; snapshot-схема 2); по нему обновлены строки FR-WORLD-013, FR-DIALOG-002, FR-SCRIPT-003/004 и FR-LIFECYCLE-003.
