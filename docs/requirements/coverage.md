# Матрица функционального покрытия

Статус каждого требования пересверен **2026-10-20** задачей ARC-DEV-027 по merged main [`e9a1356`](https://github.com/Simarglok/arcanum-steamwoven/tree/e9a1356) (последний влитый PR #268). Источники среза: код и тесты main, [каталог компонентов](../project/status.md), контракты в `docs/world`, `docs/rendering`, `docs/scripting`, `docs/audio`, `docs/formats` и исследования в `docs/research`. Новых сборок, запусков игры и проверок на оригинальных данных при пересверке не было; названные проверки — это проверки задач, которые их поставили.

Эта таблица — **статус требований**. Описание требования, поведение оригинала, приёмка и исследование остаются в доменных документах; при расхождении текущего статуса с полем «Steamwoven» доменного документа верна эта таблица. Строки требований лежат в файлах [разделов](#разделы), по одному на доменный документ. Задача, которая меняет покрытие требования, обновляет его строку в файле раздела и счётчики раздела в сводке в том же PR ([правило](../workflow/tasks.md#functional-requirements)).

## Шкала статуса

| Статус | Что значит |
| --- | --- |
| Реализовано | Поведение требования работает в игровом пути (AREA viewer, режим карты) на всех картах, которые он открывает, и закрыто проверками задачи. Допустимы только оговорки о паритете с оригиналом и о главной карте; они названы в строке. |
| Частично — во вьюере | Часть поведения работает и видна во вьюере; чего нет, названо в строке. |
| Частично — без хоста | Код данных или правил влит и проверен тестами, но во вьюере ещё не подключён (нет хоста, UI или вызывающего). |
| Исследовано | Есть исследование оригинала (иногда и чтение данных), кода, реализующего само требование, нет; смежный код может быть и назван в строке. |
| Не начато | Ни кода требования, ни целевого исследования; смежные упоминания названы в строке. |

«Вьюер» — диагностический `crash-site-area` Terrain Viewer: Crash Site снаружи и пещера, [режим карты](../rendering/area-map-mode.md) для 80 интерьеров и главной карты мира окнами (`./arcanum map NAME`; с ARC-RENDER-028 `./arcanum area` — это режим карты главной карты у Crash Site). Игры, главного меню и экспорта игрового билда нет. Паритет с оригинальным `Arcanum.exe` проверяется по [журналу сверки](../research/original-verification-ledger.md) и [реестру функций](../verification/README.md); пометка «сверено с exe» относится к правилам, а не к виду на экране.
