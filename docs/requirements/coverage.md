# Матрица функционального покрытия

**Проект реестра для аппрува владельцем.** Это сводка доменных таблиц на Steamwoven `b1245e59c585c7b7b03dd0b764e2d3e31d0f89ae`, а не процент готовности. Условия и источники находятся в подробных FR; проверки ниже — только объявленные исторические проверки ограниченных компонентов, не новый прогон оригинальной игры.

Отдельно учитываются данные, правила, интеграция и проверка. «Частично» не закрывает функцию; «Нет» не отрицает её наличие в оригинале. `Неприменимо` используется там, где соответствующее измерение не относится к самой функции (например, данные для настройки ввода). Закрытие Hermes-карточки не меняет эту таблицу автоматически. См. [правила обновления](README.md#как-читать-и-обновлять-покрытие).


Всего 183 группы требований в 10 разделах. Эта таблица сохраняет отдельные границы четырёх измерений; подробный сценарий приёмки открывается по ID.
