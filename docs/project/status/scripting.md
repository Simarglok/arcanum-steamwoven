# Component catalogue: Dialog and scripting

Part of the [project status and component catalogue](../status.md), which holds the audit note, the one-line index of every component and the rules for maintaining it. This file holds the full rows of the dialog and scripting area; a change to a component edits its row here, and a new component adds its row here and one line in the index.
