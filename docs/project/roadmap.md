# High-level dependency roadmap

This is a product dependency map, not a task queue or authorization to implement a milestone. Active cards, assignments and acceptance contracts live on Hermes board `arcanum-steamwoven`. The [status catalogue](status.md) anchors existing work; [vision](vision.md) anchors accepted direction. The foundation and finite diagnostic integration below now exist at the [recorded baseline](status.md). Subsequent stages remain proposed sequencing, not agreed detailed implementation contracts or dates.

| Stage | Depends on | Outcome and gate before expansion |
| --- | --- | --- |
| Current foundation | Reviewed research and bounded Data/Presentation/Scripting components | Maintain source-linked scope, toolchain and uncertainty. Existing loaders/viewers/labs do not prove a full game. |
| Diagnostic terrain + scenery integration | Terrain viewer, selected object/resource metadata, placement evidence | Implemented by ARC-RENDER-004 for terrain plus exactly five admitted static objects, with explicit source selection and diagnostic ordering. General scenery coverage and original placement/order/occlusion parity remain separate work. |
| Actor visual placement evidence | ARC-RES-009’s selected single-layer idle/walk chain; ARC-RES-010 pinned-source placement trace | ARC-RENDER-005 authorizes a stationary, caller-labelled, fixed-profile diagnostic presentation before parity. The next parity evidence gate remains an independent observation of the source-derived actor world-anchor-to-top-left relation, including applicable facing/flip behavior and controlled location/camera delta. Preserve the contract’s NOT READY status and do not substitute scenery rules or visual nudges. |
| Actor and movement foundations | Ready actor visual contract; admitted timeline semantics; investigated map/collision/navigation data | The [selected-sector passability evidence](../research/sector-passability-evidence.md) is a NOT READY gate: its base-mask facts do not yet resolve tile-name, static spatial, actor/state, diagonal, or cross-sector dependencies. These gates constrain original-world movement, not the already-authorized stationary diagnostic presentation. Dual-stick/Follow UX already exists in the separate synthetic lab; integration and physical Bluetooth checks remain. The CE path study is evidence with gaps, not an implemented route finder. |
| Minimal world interaction and dialog | Stable actor/world identity, targeting, bounded dialog runtime and state ports | One admitted interaction and dialog integrated with world state, with documented frontier/failure behavior. |
| Small playable slice | Combined scene, actor motion, obstacle handling, interaction/dialog, input integration | A small reproducible scene with keyboard/mouse and gamepad, meaningful checks and human observations. Scope still does not imply the complete Crash Site or original game. |
| Gameplay expansion | Verified slice and newly researched dependencies | Extend scripting/quests, inventory, combat, persistence and transitions incrementally; each contract preserves compatibility evidence and unsupported cases. |
| Compatibility and presentation expansion | Behavioral evidence and stable simulation boundary | Validate Legacy compatibility and other platforms; subsequently upscale original frames/directions one-to-one. New animation directions/frames and 3D require separate future decisions. |

Where dependencies permit, bounded data research and controller UX exploration can proceed independently. Neither constitutes approval to launch workers, create cards, change shared profiles, or dispatch the whole roadmap. Original-runtime comparison and evidence lineage remain gates throughout, not a final label granted by green synthetic tests.
