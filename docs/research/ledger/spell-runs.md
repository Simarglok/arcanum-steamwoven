## Spell invocation (ARC-MAGIC-006)

Source: the [spell invocation runtime](../../world/spell-invocation-runtime.md) (slice MT7 of the
[magic implementation plan](../magic-implementation-plan.md)) and the [magic core](../magic-core-evidence.md#choosing-the-target-fr-magic-003).
Read on 2026-10-21 by this task and, independently, by a second reader that saw only the questions (method step 6). They
agree on every row. The second reader added the structure's initialiser (0x455A20: the object the run starts from at +0x8,
the caster at +0x40 through 0x450A50, the caster's location at +0x38), the meaning of the anti-teleport test's zones, what the
uninitialised slot of the line of fire holds (IV4, checked again by the first reader) and the callers of the item gate; the
first reader confirmed in the target collection (0x4F40B0, its 0x200000 branch) that the fallback's value 2 is the radius. The
range (0x454700), the forbidden flags (0x456430) and the item gate (0x456A10) were run in the function oracle on 10,000 seeded
inputs each (receipts in `docs/verification/receipts`): Steamwoven matches on every input, every planted mutant caught (F3).
The check itself (0x4564E0) and the line of fire (0x456BC0) call the area and line functions and stay F2. Every direct branch
stays inside `.text`.

The check's structure, as both readers name it here: the spell (+0x0); the **source**, the object the invocation starts from
(+0x8: the caster for its own spell, else the item); the **parent**, the caster (+0x40: the source itself, or an item's holder,
field 0x58, when the item is in an inventory); the source's location (+0x38: 0x455A20 fills it from the object it is given, the source; corrected by ARC-MAGIC-009); the target object (+0x70, its reference's id
word +0x78) and the target tile (+0xD0, a 64-bit location, x in the low half; 0 is none).
